# v0.11.9 - AGY quota and desktop footprints

## Changes

- Connect Antigravity account quota from the desktop store through the authenticated gateway to Android. Gemini and third-party model five-hour/weekly windows remain independent; missing quota is not displayed as 100% remaining. Preserve original observation timestamps and stale/offline labels.
- Replace the Devices navigation entry with native Footprints. View today, this week (Monday start), this month and this year; session starts, completed turns, tool calls, activity signals, hourly bars and daily heatmaps use the desktop's persisted recap aggregates.
- Keep unsupported metrics as unknown and mark partial totals explicitly. No recording is not zero activity, and signal counts are not working minutes. Quota remains a current allowance, not historical token spending.
- Keep connection diagnostics under the Footprints page's Connection Information button. Preserve soft cards and light/dark themes.
- Fetch footprints only on page entry, period change, manual refresh or reconnect/resume while visible. No new background polling, wake lock, provider API query, or heartbeat change. In-memory range caches survive connection loss but not process restart and are cleared when connection configuration changes.
- Add a credential-free read-only gateway adapter and deployment patch. No desktop application bundle changes; no raw journals, session text, identity hashes, private paths or pairing secrets are sent in footprints.

## Verification

- Local Android build, Lint and 88 focused JUnit tests passed; gateway adapter has 6 passing Node tests, alongside 11 existing animation policy assertions.
- Public authenticated WebSocket returned all four AGY windows and ready snapshots for all four footprint ranges. Health endpoint returned HTTP 200. Current yearly footprint payload is about 42 KiB.
- Exact source commit and upgrade-compatible local debug signing certificate are validated by packaging. The existing v0.11.6/7/8 signing lineage is retained.
- No attached phone was available: physical installation, visual acceptance in both themes, scrolling and real battery/network-switch tests remain unverified. This is a prerelease, not a claim of completed phone acceptance. The inherited full-suite coroutine countdown issue remains outside scope.

## Deployment and download

Install `Clawd-Mobile-0.11.9-debug.apk` from this repository's Release page over the existing same-signature version. Do not use the incompatible Actions CI APK.

The local gateway has already been updated, with a backup of its prior script. For other deployments, see `gateway/README.md`. Existing pairing credentials, tunnel and signed desktop app are unchanged. Old releases are preserved.
