# Clawd Mobile v0.11.7 连接诊断与额度新鲜度测试版

## 功能

- 局域网和远程连接分别显示状态、最近成功时间及故障提示。
- 认证失败、DNS、TLS、超时、服务故障和电脑端离线不再全部归为“未连接”。
- 额度显示更新时间；断线标为离线数据，超过 30 分钟标为过期。
- 显示最多两组 Codex 额度窗口，沿用网关提供的剩余额度，不重新计算官方账单。
- 保留原有柔和卡片、浅色/深色模式、悬浮桌宠与重连机制。
- 关于页显示构建提交，并连接到 ZhongShiJie-Code 的下载仓库。

## 安装与追溯

包名 `com.clawd.mobile`，版本 `0.11.7`，versionCode `1014`。沿用 v0.11.6 的 Android Debug 签名证书。源码由 Release 标签定位，APK 内嵌相同提交。下载后可用 `SHA256SUMS` 校验；`release-manifest.json` 记录版本、源码提交、签名证书指纹和安装包哈希。

## 已完成验证

- Android Debug 构建与 Lint。
- 46 项定向单元测试（连接状态、诊断、额度时间、消息解析、客户端状态）。
- 网关时间元数据 3 项断言。
- 合法配对可接收 WebSocket `usage_snapshot`；无效凭证返回 HTTP 401。
- 新旧安装包签名证书一致。

## 尚未完成

- 真实手机覆盖安装及浅色/深色界面验收。
- Wi-Fi/5G 切换、锁屏待机、电脑睡眠恢复和长时间耗电验收。
- 完整单元测试套件：既有授权倒计时测试持续循环，本次只报告定向测试通过。

因此本版标为测试版，不宣称手机端端到端验收已经完成。旧版本全部保留。
