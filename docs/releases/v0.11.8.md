# Clawd Mobile v0.11.8 保守省电测试版

## 改动范围

- 熄屏卸载悬浮宠物渲染页面，连接、授权提醒和状态接收保持运行。亮屏恢复最新状态，不回放旧事件。
- 稳定闲置和睡眠状态的 SVG CSS 动画按 20 帧采样，保留原缓动和播放时长；工作、思考、完成、异常及互动动画保持正常播放。静态图不启动采样计时器。
- 无网络时暂停重连计时器；默认网络恢复后立即恢复重连。保留原有指数退避、认证失败、证书确认和手动断开行为。
- 工具输出刷新在 100 毫秒窗口内合并，始终发布最新数据。状态切换、会话快照和删除立即刷新；授权与反应事件不进入合并队列。
- 手机额度继续使用服务端推送，不增加后台查询；已有 StateFlow 相等值去重继续保留。额度新鲜度标记正常更新。
- 不改变唤醒锁、Wi-Fi 锁、心跳周期和前台服务策略。

## 限制与验收

本地 Debug 构建、Lint、82 项定向单元测试和 11 项动画策略断言通过。包名不变，versionCode 为 1015；打包时验证与 v0.11.6/v0.11.7 相同签名及内嵌源码提交。

APNG 不做闲置降帧，只做熄屏停止渲染，避免破坏图片解码和播放时序。

需要真机验证：覆盖安装、亮屏/锁屏恢复、连续授权、任务结束反馈、Wi-Fi/5G 切换及无网络恢复。需在相同手机和使用条件下测量耗电，尚不能宣称省电百分比。

完整单元测试套件中的既有授权倒计时循环问题未纳入本次修复，执行定向回归测试而非宣称全套通过。
